## Skills I Want To Learn

While traditional curriculum often focuses on older frameworks like Bootstrap, modern industry standards have shifted toward tools like Tailwind CSS and modern UI component libraries like shadcn/ui. My goal is to move past legacy methods and focus heavily on the high-demand, modern technologies that are actually used in production today.
